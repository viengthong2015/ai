1. ບົດນຳ (Introduction)

ໃນປັດຈຸບັນ, ລະບົບສາທາລະນະສຸກພວມກຳລັງຫັນປ່ຽນໄປສູ່ຍຸກດິຈິຕອນ ທີ່ມີການນຳໃຊ້ເຕັກໂນໂລຊີ ແລະ ລະບົບຖານຂໍ້ມູນເຂົ້າໃນການຄຸ້ມຄອງບໍລິການສາທາລະນະສຸກຢ່າງກວ້າງຂວາງ. ການປ່ຽນແປງນີ້ເຮັດໃຫ້ມີຂໍ້ມູນດ້ານການສາທາລະນະສຸກຖືກສະສົມໄວ້ເປັນຈຳນວນຫຼວງຫຼາຍ ເຊິ່ງຊື່ງສາມາດເປັນຂໍ້ມູນພື້ນຖານ (baseline) ໃຫ້ເຮົາ ເພື່ອໄປເຮັດການຄາດຄະເນໃນອານາຄົດ ແລະ ການວາງແຜນ ຕໍ່ວຽກງານການບໍລິການສາທາລະນະສຸກ. ບັນຫາທີ່ພົບເລື້ອຍໃນສະຖານທີ່ບໍລິການສາທາລະນະສຸກແມ່ນ ອັດຕາການປີ່ນປົວພະຍາດ, ອັດຕາການສັກຢາກັນພະຍາດ, ...ຍັງຕ່ຳເນື່ອງມາຈາກຕົວເລກເປົ້າໝາຍກຸ່ມປະຊາກອນບໍ່ຊັດເຈນ ເປັນສາຍເຫດເຮັດໃຫ້ການວາງແຜນບໍ່ຖືກຕາມສະພາບຕົວຈິງ.

ດ້ວຍເຫດນີ້, ການນຳໃຊ້ເຕັກນິກ ການຮຽນຮູ້ຂອງເຄື່ອງຄອມພິວເຕີ (Machine Learning) ເຂົ້າໃນການພະຍາກອນຕົວເລກປະຊາກອເປົ້າໝາຍ ຈຶ່ງມີຄວາມສຳຄັນ ແລະ ເປັນແນວທາງຮູບແບບໃໝ່ທີ່ມີປະສິດທິພາບສູງ. ການພະຍາກອນປະຊາກອນແບບນີ້ ຈະຊ່ວຍໃຫ້ຂະແໜງສາທາລະນະສຸກ ສາມາດຮູ້ເປົ້າໝາຍປະຊາກອນທີ່ຊັດເຈນ ເພື່ອການວາງແຜນການບໍລິການສາທາລະນະສຸກໃຫ້ມີປະສິດພາບດີຂື້ນ.

ຄວາມສຳຄັນຂອງວຽກງານນີ້ ຈະຊ່ວຍປ່ຽນຮູບແບບການບໍລິຫານການສຸຂະພາບຈາກ "ການຕັ້ງທ່າຮັບ" ມາເປັນ "ການປ້ອງກັນ ແລະ ຄາດການລ່ວງໜ້າ".

ດັ່ງນັ້ນ, ງານວິໄຈສະບັບນີ້ຈຶ່ງມຸ່ງສຶກສາ ແລະ ພັດທະນາແບບຈຳລອງການພະຍາກອນຕົວເລກປະຊາກອນໃນອານາຄົດ ເພື່ອເປັນເຄື່ອງມືສະໜັບສະໜູນການຕັດສິນໃຈ ໃຫ້ແກ່ຂະແໜງສາທາລະນະສຸກໃນການພັດທະນາຄຸນນະພາບການບໍລິການສາທາລະນະສຸກໃຫ້ມີຄຸນນະພາບ ແລະ ຍືນຍົງໃນຍຸກດີຈີຕອນ.

2. ຈຸດປະສົງ

2.1. ຈຸດປະສົງລວມ

1

ເພື່ອມີຕົວເລກຄາດໝາຍທີ່ຊັດເຈນຕໍ່ການວາງແຜນການບໍລິການສາທາລະນະສຸກ

ປະສິດທິພາບຂອງ models
2

ເພື່ອພັດທະນາ ແລະ ປຽບທຽບປະສິດທິພາບ ຂອງແບບຈຳລອງ (Models) ໃນການພະຍາກອນຕົວເລກປະຊາກອນ

ສ້າງເຄື່ອງມື
3

ເພື່ອສ້າງເຄື່ອງມືສະໜັບສະໜູນການຕັດສິນໃຈໃຫ້ຂະແໜງສາທາລະນະສຸກ

2.2. ຈຸດປະສົງສະເພາະ
ພະຍາກອນຕົວເລກປະຊາກອນໃນແຕ່ລະປີ
1

ພະຍາກອນປະຊາກອນ ປີ —

ປຽບທຽບຄຸນນະພາບຂອງແຕ່ລະແບບຈຳລອງ
2

ປຽບທຽບປະສິດທິບພາບຂອງແຕ່ລະແບບຈຳລອງ (Models) ແລະ ຕັດສິນໃຈເລືອກແບບຈຳລອງທີ່ຄຸນນະພາບດີທີ່ສຸດ

ເຂົ້າໃຈເລິກໃນວິຊາ ML
3

ເຂົ້າໃຈຕໍ່ກັບການປັບຄ່າຕ່າງໆ (Hyperparameter Turning) ເພື່ອປະສິດທິພາບຂອງແຕ່ລະແບບຈຳລອງ

3. ຊຸດຂໍ້ມູນທີ່ໃຊ້ (Data set)

ຊຸດຂໍ້ມູນທີ່ນຳໃຊ້ໃນການວິໄຈຄັ້ງນີ້ ແມ່ນໄດ້ມາຈາກລະບົບຖານຂໍ້ມູນຂອງກະຊວງສາທາລະນະສຸກ (DHIS2) ເປັນຊຸດຂໍ້ມູນທີ່ສົມບູນແບບ (ບໍ່ມີຂໍ້ມູນຊ້ຳຊ້ອນ, ບໍ່ມີຂໍ້ມູນທີ່ຂາດຫາຍ (missing value), ...). ຂໍ້ມູນທັງໝົດ — ແຖວ (records)

ໂຄງສ້າງຂອງຊຸດຂໍ້ມູນ ໄດ້ຖືກຄັດເລືອກ ແລະ ແບ່ງອອກເປັນແຕ່ລະປເພດຄື:

  • ເພດ (ຍິງ, ຊາຍ)

y(Target):
  1. ຈ.ນ ປະຊາກອນເປັນແຕ່ລະປີ (2026-2030),
  2. ຈ.ນ ປະຊາກອນເປັນແຕ່ລະເມືອງ,
  3. ຈ.ນ ປະຊາກອນເປັນກຸ່ມອາຍຸ (0, 1, 2, ..., 80+ ປີ)
  4. ຈ.ນ ປະຊາກອນແບ່ງເປັນເພດ (ຍິງ, ຊາຍ)
Learning Technique
ແບບຈຳລອງ (Models)

LinearRegression:

  1. ຄຸນລັກສະນະ: ຕົວປ່ຽນເອກະລາດ (x) ແລະ ຕົວປ່ຽນຕາມ (y) ມີຄວາມສຳພັນກັນໃນອັດຕາທີ່ ຄົງທີ່ (ຖ້າ x ເພີ່ມ 1 ໜ່ວຍ, y ຈະປ່ຽນແປງໃນຈຳນວນທີ່ເທົ່າກັນສະເໝີ)

  2. ສົມຜົນຫຼັກ: y = β0 + β1x
  3. ຂໍ້ດີ/ຂໍ້ເສຍ: ງ່າຍຕໍ່ການນຳໃຊ້ ແລະ ແປຜົນ, ແຕ່ບໍ່ສາມາດໃຊ້ໄດ້ດີກັບຂໍ້ມູນທີ່ມີລັກສະນະເປັນເສັ້ນໂຄ້ງ ຫຼື ມີຄວາມຊັບຊ້ອນສູງ.
PolynomialFeatures:

  1. ຄຸນລັກສະນະ: ສາມາດປັບຕົວເຂົ້າກັບຂໍ້ມູນທີ່ມີການ, ໂຄ້ງເປັນຮູບຕົວ U, ຫຼື ມີຈຸດສູງສຸດ/ຕໍ່າສຸດໄດ້ (Non-linear relationships). ມັນເຮັດວຽກໂດຍການປ່ຽນຄ່າ x ໃຫ້ກາຍເປັນ x2, x3, … ແລ້ວຈຶ່ງນຳໄປຄຳນວນແບບເສັ້ນຊື່.

  2. ສົມຜົນຫຼັກ: y = β0 + β1x + β2x2 + … + βnxn

  3. ຂໍ້ດີ/ຂໍ້ເສຍ: ມີຄວາມຢືດຢຸ່ນສູງ ແຕ່ຕ້ອງລະວັງບັນຫາ Overfitting ຢ່າງໜັກ (ແບບຈຳລອງຈື່ຈຳຂໍ້ມູນເກົ່າໄດ້ດີ ແຕ່ພະຍາກອນຂໍ້ມູນໃໝ່ຜິດພາດ) ຖ້າກຳນົດຄ່າ Degree ສູງເກີນໄປ.

Exponential Growth (Log-Linear Regression)

  1. ຄຸນລັກສະນະ: ແທນທີ່ຈະພະຍາກອນຄ່າ y ໂດຍກົງ, ໂມແບບຈຳລອງຈະປ່ຽນຄ່າ y ໃຫ້ກາຍເປັນ Logarithm (ເຊັ່ນ ln(y)) ເພື່ອເຮັດໃຫ້ກເສັ້ນສະແດງທີ່ໂຄ້ງຂຶ້ນຢ່າງໄວວາກາຍເປັນເສັ້ນຊື່ ແລ້ວຈຶ່ງໃຊ້ Linear Regression ມາຄຳນວນ.

  2. ສົມຜົນຫຼັກ: y = a · ebx ເຊິ່ງປ່ຽນຮູບແບບໄດ້ເປັນ ln(y) = ln(a) + bx

  3. ຂໍ້ດີ/ຂໍ້ເສຍ: ເໝາະສຳລັບຂໍ້ມູນສະເພາະທາງເຊັ່ນ: ການເພີ່ມຂຶ້ນຂອງປະຊາກອນ, ການແຜ່ລະບາດຂອງໄວຣັສ, ຫຼື ການເຕີບໂຕຂອງດອກເບ້ຍຕໍ່ຕົ້ນທຶນ.

# Shared model implementation (population_forecast.py)
def forecast_totals(df, future_end=2030):
    if future_end < 2026:
        raise ValueError("The forecast end year must be 2026 or later.")

    historical_x = np.asarray(HISTORICAL_YEARS).reshape(-1, 1)
    all_years = np.arange(HISTORICAL_YEARS[0], future_end + 1)
    all_x = all_years.reshape(-1, 1)
    y = df[HISTORICAL_COLUMNS].sum(axis=0).to_numpy(dtype=float)

    linear = LinearRegression().fit(historical_x, y)

    polynomial_features = PolynomialFeatures(degree=2)
    historical_poly = polynomial_features.fit_transform(historical_x)
    polynomial = LinearRegression().fit(historical_poly, y)

    # Match the notebook while preventing log(0) for an empty subgroup.
    exponential = LinearRegression().fit(
        historical_x, np.log(np.where(y <= 0, 0.1, y))
    )

    predictions = {
        "Linear": linear.predict(all_x),
        "Polynomial": polynomial.predict(
            polynomial_features.transform(all_x)
        ),
        "Exponential": np.exp(exponential.predict(all_x)),
    }
    train_size = len(HISTORICAL_YEARS)
    fitted = {name: values[:train_size] for name, values in predictions.items()}
    future = {name: values[train_size:] for name, values in predictions.items()}
    metrics = pd.DataFrame(
        [_metrics(y, fitted[name]) for name in MODEL_NAMES],
        index=MODEL_NAMES,
    )
    metrics.index.name = "Model"
    return ForecastResult(y, all_years, predictions, fitted, future, metrics)

# Vectorized multi-output method (population_forecast.py)
def forecast_each_row(df, future_end=2030):
    future_years = np.arange(2026, future_end + 1)
    historical_x = np.asarray(HISTORICAL_YEARS).reshape(-1, 1)
    future_x = future_years.reshape(-1, 1)
    values = df[HISTORICAL_COLUMNS].to_numpy(dtype=float).T

    linear = LinearRegression().fit(historical_x, values)
    linear_predictions = linear.predict(future_x).T

    polynomial_features = PolynomialFeatures(degree=2)
    historical_poly = polynomial_features.fit_transform(historical_x)
    polynomial = LinearRegression().fit(historical_poly, values)
    polynomial_predictions = polynomial.predict(
        polynomial_features.transform(future_x)
    ).T

    safe_values = np.where(values <= 0, 0.1, values)
    exponential = LinearRegression().fit(
        historical_x, np.log(safe_values)
    )
    exponential_predictions = np.exp(
        exponential.predict(future_x)
    ).T

    result = df.reset_index(drop=True).copy()
    model_predictions = {
        "Linear": linear_predictions,
        "Poly": polynomial_predictions,
        "Exp": exponential_predictions,
    }
    for suffix, predictions in model_predictions.items():
        rounded = np.rint(predictions).clip(min=0).astype(np.int64)
        for position, year in enumerate(future_years):
            result[f"{year}_{suffix}"] = rounded[:, position]
    return result

# Exact metric method used by population_forecast.py
def _metrics(y_true, y_pred):
    nonzero = y_true != 0
    mape = (
        float(
            np.mean(
                np.abs(
                    (y_true[nonzero] - y_pred[nonzero])
                    / y_true[nonzero]
                )
            ) * 100
        )
        if nonzero.any()
        else float("nan")
    )
    return {
        "MAE": float(mean_absolute_error(y_true, y_pred)),
        "RMSE": float(np.sqrt(mean_squared_error(y_true, y_pred))),
        "MAPE (%)": mape,
        "R²": float(r2_score(y_true, y_pred)),
        "Accuracy (%)": 100 - mape,
    }

metrics = pd.DataFrame(

Error Analysis & Accuracy
Linear Regression
  • R²: — Coefficient of Determination (R²) Measures how much variation in the actual values the model explains. Values closer to 1 indicate a better fit.
  • Accuracy: — Accuracy (100 − MAPE) Shows the model's average percentage closeness to the actual values. Higher values indicate closer predictions.
  • MAE: — Mean Absolute Error (MAE) The average absolute difference between actual and predicted values. Lower values indicate smaller errors.
  • RMSE: — Root Mean Squared Error (RMSE) Measures prediction error while giving more weight to large mistakes. Lower values indicate a better fit.
  • MAPE: — Mean Absolute Percentage Error (MAPE) The average absolute prediction error expressed as a percentage of actual values. Lower values are better.
